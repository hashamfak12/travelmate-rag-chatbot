# TravelMate – RAG Chatbot for Travel Guides

TravelMate is a Retrieval-Augmented Generation (RAG) chatbot that I built for my CS 156 Final Project. The goal of the project is to answer travel-related questions using actual travel guides instead of relying only on an LLM. The system retrieves information from a comprehensive dataset of city travel guides and uses those snippets to answer user questions.

I used **FAISS** for vector similarity search, **SentenceTransformer** embeddings for encoding text, and **Streamlit** for the user interface.

---

## What the Project Can Do

- Search through real travel guide files and pull out relevant information  
- Show the top-k retrieved snippets along with citations  
- Provide answers through a clean Streamlit interface  
- Optionally support LLM-generated answers (if an API key is added)  
- Evaluate retrieval quality using precision@k and latency  

Even without an LLM enabled, the system still works and shows grounded answers through retrieved snippets.

---

## Travel Data

The dataset includes comprehensive travel guides for **14 cities** across 6 continents:

**Europe:** Paris, London, Rome, Berlin  
**Asia:** Tokyo, Bangkok, Mumbai, Singapore  
**North America:** New York, Mexico City  
**South America:** São Paulo  
**Africa:** Cape Town  
**Oceania:** Sydney  
**Middle East:** Dubai  

Each city guide includes:
- Airport information and transportation
- Getting around the city
- Major attractions with details
- Accommodation options
- Food and dining recommendations
- Practical travel tips

**Data Sources:** All travel guides include citations referencing Wikivoyage and official tourism board sources. See individual data files for complete source attributions.

## Project Structure

```

├── data/              # Travel guide text files (14 cities)
├── index/             # FAISS index (generated by ingest.py)
├── eval/              # Evaluation questions

│   ├── embeddings.py  # Embedding model loading

├── app_streamlit.py   # Streamlit UI
├── ingest.py          # Builds FAISS index from data/

```

## How to Run the Project

### 1. Create and activate a virtual environment
```bash
python -m venv .venv
# Windows PowerShell
.venv\Scripts\Activate.ps1
# Windows CMD
.venv\Scripts\activate.bat
# macOS/Linux
source .venv/bin/activate
```

### 2. Install Requirements
```bash
pip install -r requirements.txt
```

### 3. Build the FAISS index
```bash
python ingest.py --data_dir ./data --index_dir ./index --chunk_size 500 --chunk_overlap 50
```

### 4. Run the Streamlit app
```bash
streamlit run app_streamlit.py
```
